# Study Notes Manager

A study notes and resource manager for organizing notes by course, tracking review progress, and uploading files.

## Built With
- React
- Node.js
- MongoDB

## User Stories
- As a student, I want to add a study note with a title and subject so I can keep track of what I've learned.
- As a student, I want to view all my notes organized by subject so I can find them quickly before exams.
- As a student, I want to mark a note as "reviewed" so I can track my exam prep progress.
- As a student, I want to upload a file (PDF or image) with a note so I don't lose handwritten material.
- As a student, I want to delete notes I no longer need.
